Build: `make paper` (needs pdflatex + bibtex). For the ACL look, put `acl.sty` and `acl_natbib.bst` from https://github.com/acl-org/acl-style-files into `paper/`
(without them a plain article layout is used). All numbers come from `tables/macros.tex` and `tables/main.tex`, generated by `covert eval report`; missing numbers render as red TODO.
Page rule: body <= 8 pages before "Challenges, Limitations and Future Work"; `make paper` runs `scripts/check_pages.py`.
