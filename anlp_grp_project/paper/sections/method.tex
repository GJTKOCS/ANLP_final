\section{Method: Adversarial Multi-turn GRPO}
\paragraph{Listeners.} Both listeners are one class: a causal-LM backbone with LoRA, last-non-pad-token pooling, and two linear heads (helper, venue) trained with the sum of cross-entropies.
The B and C listeners differ only in the input view (with or without memories); they share backbone, LoRA configuration, hyperparameters, seed, training examples and number of steps, which we assert in code and record in manifests.
\paragraph{Speaker warm start.} The speaker is a LoRA adapter on a small instruct model. A larger generator plays A (with the secret) and B (without it); we keep conversations in which A does not leak, the sense judge passes, a prompted B (memories) recovers both slots and a prompted C (rules and three solved examples) recovers at most one.
Supervised fine-tuning on A turns of these conversations gives the \emph{sft} adapter (condition S1), which is also the KL reference.
\paragraph{Reward.} For one rollout, $r=-1$ if A leaks or the judge's score $<\tau$; otherwise $r=\tfrac12(p_B^{h}+p_B^{v})-\lambda\,\tfrac12(p_C^{h}+p_C^{v})$ where $p$ is the probability a frozen listener assigns to the true value.
A clipped-bits variant is available. $\tau$ is calibrated on good versus corrupted conversations.
\paragraph{GRPO.} For $P$ episodes we sample $G$ rollouts each (A turns from the policy adapter, B turns from the frozen base model with adapters disabled, resampling B turns that leak). Advantages are group-normalised, $A_i=(r_i-\bar r)/(\sigma+10^{-4})$; groups with zero variance contribute nothing.
The loss is computed on A-turn tokens only: a PPO-style clipped surrogate ($\epsilon=0.2$) plus $\beta\,\mathrm{KL}$ to the sft reference (k3 estimator), averaged over tokens within a sequence and then over sequences.
\paragraph{Rounds.} Round 0 trains listeners $L_0$ on all warm-start conversations. In round $r$ the speaker is trained against frozen $L_{r-1}$; we then generate transcripts from the new speaker and train $L_r$ on the warm-start data plus all speaker transcripts so far (cumulative, so C never forgets a trick it caught).
\paragraph{Evaluation recipe.} For each speaker condition we generate one conversation per train and test episode, train a \emph{fresh} B and C pair on that condition's training transcripts, and evaluate on its test transcripts. Only the A speaker changes between conditions; the B speaker, judge, leak checker and episodes are identical.
