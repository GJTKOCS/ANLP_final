\section{Experimental Setup}
\paragraph{Models.} Speaker: Qwen2.5-3B-Instruct with LoRA ($r{=}16,\alpha{=}32$). Generator, prompted listeners and C$_\text{alt}$: \x{bigGen} (bf16). B speaker and sense judge: the base 3B model with adapters disabled. One NVIDIA H100 80\,GB.
\paragraph{Data.} \x{nTrain} train, \x{nDev} dev and \x{nTest} test episodes; test uses held-out cover topics and memory themes. \x{slotFallbackPct}\% of memory slots fell back to a template sentence after three failed LLM attempts, and only \x{bankAllLLMPct}\% of banks were written entirely by the LLM (Section~\ref{sec:limits}).
The warm start produced \x{warmN} conversations (3 per training episode), of which \x{warmGood} were good; on them prompted B recovered both slots \x{warmBboth}\% of the time, prompted C \x{warmCboth}\%, and A leaked in \x{warmLeak}\%.
\paragraph{Training.} SFT: 2 epochs, learning rate $10^{-4}$. GRPO: one round of \x{grpoSteps} steps with $P{=}8$ episodes and $G{=}6$ rollouts per step, learning rate $10^{-5}$, $\beta{=}0.04$, temperatures 0.9 (A) and 0.7 (B), \x{grpoHours}\,GPU-hours, \x{nRollouts} rollouts in total. The dev reward was measured every 25 steps; S3 uses the checkpoint with the best dev reward (step \x{bestDevStep}, reward \x{bestDevReward}). Base weights were verified unchanged after GRPO (frozen: \x{baseFrozen}).
\paragraph{Conditions.} S0: base 3B prompted (no adapter). S1: SFT warm start. S3: GRPO. The planned best-of-8 baseline (S2), the large-model speaker (S4), a second GRPO round and $\lambda\in\{0.5,2\}$ were not run within the compute budget (Section~\ref{sec:journey}).
\paragraph{Metrics.} Per-slot and both-correct accuracy of B, C and C$_\text{alt}$; insider advantage (B both minus C both); joint success (B both correct, C at most one slot correct); leak rate; sense pass rate. 95\% bootstrap intervals over test episodes (1000 resamples). Chance: 10\% per slot, 1\% both.
